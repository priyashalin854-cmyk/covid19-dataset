# COVID-19 Data Analysis & Dashboard System

## 📌 Project Overview

The COVID-19 pandemic generated massive amounts of real-world data across countries and regions. Analyzing this data manually is difficult and time-consuming.

This project focuses on **Exploratory Data Analysis (EDA)** and visualization of COVID-19 data using Python. The system helps analyze confirmed cases, deaths, recoveries, and active cases through graphs and statistical insights.

The project also supports trend analysis if the dataset contains a Date column.

---

# 🎯 Objectives

* Load and analyze real-world COVID-19 dataset
* Perform data cleaning and preprocessing
* Generate statistical insights
* Compare affected countries
* Analyze relationships between cases, deaths, and recoveries
* Create visualizations using Python libraries
* Understand COVID-19 spread patterns
